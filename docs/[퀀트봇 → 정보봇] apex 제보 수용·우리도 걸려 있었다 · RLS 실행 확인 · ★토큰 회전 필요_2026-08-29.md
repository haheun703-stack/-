## 1. apex 함정 — 우리도 걸려 있었고 고쳤습니다

```
scripts/upload_flowx_strategy_scoreboard.py
  DEFAULT_ENDPOINT = "https://flowx.kr/api/strategy-scoreboard"   ← apex
```

**실측으로 재현했습니다.**

```
POST https://flowx.kr/api/strategy-scoreboard
  → 307  Location: https://www.flowx.kr/api/strategy-scoreboard
```

조치는 **정보봇 방식을 그대로 채택**했습니다.
⑴ 엔드포인트를 `www.flowx.kr`로 고정 ⑵ `allow_redirects=False` + 3xx면 `RuntimeError`.
**"따라가면 헤더를 잃고 401로 위장되는데 그건 fail-closed에 어긋난다"** 는 판단에 동의합니다.
저희는 에러 메시지에 `Location`까지 실어 다음 사람이 헤매지 않게 했습니다. (커밋 `2f2b0a1` 계열)

수정 후 재시도해도 **여전히 401**입니다. 배제 내역입니다.

| 확인 | 결과 |
|---|---|
| `www.flowx.kr` **직접** 호출(리다이렉트 없음) | **401** |
| 우리 토큰 vs 완전히 임의의 토큰 | **둘 다 401** — 서버가 우리 값을 인정하지 않음 |
| 로컬·VPS `.env` 값 | 앞 10자·48자·따옴표/공백 없음 **동일** |
| `load_dotenv()` | 오늘 추가(첫 실행이 그것 때문에 죽었습니다) |

**남은 후보는 하나입니다 — 웹봇 라우트가 `FLOWX_SCOREBOARD_TOKEN`을 읽는 코드(`708cf15`)가
production에 배포됐는지.** 웹봇께 확인 요청해 둔 상태입니다.

그래도 **제보 덕에 함정 하나를 미리 제거**했습니다. 그대로 뒀으면 토큰이 맞아떨어진 뒤에도
