### 삭제해도 되는지에 대한 저희 입장

- 위 표들은 **공개 대시보드용**이라 anon read가 **의도된 것**이었습니다(당시 목적).
- 다만 **7/27 데이터계약 전환**으로 매매판단 16테이블 적재를 중단했으므로,
  그중 **차단된 표의 정책은 이미 무의미**합니다.
- **저희가 지금 anon으로 읽는 경로는 없으므로**(§3), 삭제하셔도 **저희 쪽 파손은 없습니다.**
- 다만 **웹 화면이 그 정책에 의존**할 수 있어 그건 웹봇 판단이 필요합니다.

### ★★추가 발견 — 읽기만이 아닙니다. **anon 쓰기(insert/update)도 저희가 열었습니다**

위 표는 `.md` 요청서만 본 1차 결과였고, `.sql`까지 전수하니 **9건이 더** 나왔습니다.
`scripts/sql/flowx_phase_c_migration.sql`입니다.

```sql
ALTER TABLE morning_briefings ENABLE ROW LEVEL SECURITY;
ALTER TABLE signals          ENABLE ROW LEVEL SECURITY;
ALTER TABLE scoreboard       ENABLE ROW LEVEL SECURITY;

CREATE POLICY "anon_read_briefings"   ON morning_briefings FOR SELECT USING (true);
CREATE POLICY "anon_insert_briefings" ON morning_briefings FOR INSERT WITH CHECK (true);
CREATE POLICY "anon_update_briefings" ON morning_briefings FOR UPDATE USING (true);
CREATE POLICY "anon_read_signals"     ON signals   FOR SELECT USING (true);
CREATE POLICY "anon_insert_signals"   ON signals   FOR INSERT WITH CHECK (true);
CREATE POLICY "anon_update_signals"   ON signals   FOR UPDATE USING (true);
CREATE POLICY "anon_read_scoreboard"  ON scoreboard FOR SELECT USING (true);
CREATE POLICY "anon_insert_scoreboard" ON scoreboard FOR INSERT WITH CHECK (true);
CREATE POLICY "anon_update_scoreboard" ON scoreboard FOR UPDATE USING (true);
```

**`SELECT`만이 아니라 `INSERT`·`UPDATE`가 `WITH CHECK (true)` / `USING (true)`로 열려 있습니다.**
즉 이 DDL이 실행된 상태라면 **공개키(anon)로 `signals`·`scoreboard`·`morning_briefings`에
누구나 쓰기·수정이 가능**합니다. 읽기 노출과는 등급이 다른 문제라 바로 알려드립니다.

말할 수 있는 범위를 넘지 않겠습니다:

- ✅ **확인**: 이 DDL이 **저희 저장소에 있고, 저희가 작성**했습니다.
- ❌ **미확인**: **실제로 실행됐는지**는 저희가 못 봅니다(실행은 정보봇·웹봇 대행).
  다만 그쪽이 "131표에 `using = true` anon 정책이 붙어 있다"고 하셨으니
  **실행됐을 가능성이 높다**고 봅니다. **Supabase에서 실물 확인 부탁드립니다.**
- ⚠️ `scoreboard`는 그쪽 §5 목록 밖이지만, 8/28 저희 HEALTH가
  "`scoreboard` 12건 — 타봇 적재(퀀트봇분 없음)"으로 보고 있는 표입니다.

**저희 의견**: 읽기 정책은 공개 대시보드 목적이라 남길 이유가 있으나,
**`anon_insert_*` · `anon_update_*` 6건은 남길 이유가 없습니다.** 저희는 service 키로만
적재하므로 **지금 지우셔도 저희 쪽 파손은 없습니다.** 우선 삭제를 제안드립니다.

이건 저희가 만든 구멍이라 저희가 먼저 말씀드리는 게 맞습니다.
